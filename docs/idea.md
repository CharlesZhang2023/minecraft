# 想法清单

这些想法放在一起看，方向是：**把这个游戏做成一个通用的"世界引擎"**。在里面可以创作，可以导入真实世界，可以搭机器、搭机器人，也可以跑仿真和 AI 实验。方块世界是统一的载体。

机器人和科研平台这条线已经单独写成了 [plan.md](plan.md)。

状态标记：✅ 已有 · 🟡 部分已有 · ⬜ 未开始

## 一、原始想法

- 音乐、绘画、雕塑
- 通过说话生成你想要的东西
- 支持 robot 描述文件（URDF）
- 支持 3DGS（3D 高斯泼溅），以及世界模型
- 做一个类似投影 mod 的 mod，并且能和原版 MC 双向导入导出存档
- 复刻 RoboMaster
- 复刻香港科技大学
- 元素反应（原神、塞尔达）
- 枪械
- 更多载具
- Besiege、坎巴拉太空计划、创世战车、废品机械师
- 导演台
- 基因、生物、果蝇大脑、AlphaFold、生命游戏、类似赛马育成游戏的基因系统
- 吸血鬼幸存者类玩法
- 上帝盒子（WorldBox）、模拟器、环世界
- 数学函数
- 强化学习：移植 Gym，比如那个登月（LunarLander）
- 创世神（WorldEdit），更好的建筑系统
- 生成像素画、音乐系统
- 在服务器里放方块先暂存，再批量固化
- 更真实的地形，WorldPainter
- 噪声加高程约束混合生成，生成香港
- 自定义方块
- 复刻 NetLogo

## 三、补充想法

这一节是第一次整理时补充的，原始清单里没有，但上面的愿景需要它们。

### 底层基础设施（最容易漏，但其他所有点子都依赖它）

- 🟡 **Python 脚本接口**：在游戏外用 Python 控制世界。AI、RL、NetLogo 复刻、数学函数都要靠它。agent 桥已经提供了 HTTP 接口、Node 客户端和 `mc` 命令，还差一个 Python 客户端。
- ⬜ **时间控制**：暂停、单步、加速、无界面运行、多实例并行。RL 和仿真必须有。`mc launch` 已经能开无界面浏览器，还差锁步。
- 🟡 **通用格式转换层**：`.schem`、`.litematic`、`.nbt`、Anvil 存档、`.vox`、`.obj/.glb`、点云、3DGS 之间的互相转换。Blueprints 已经覆盖了 MC 自己的格式，3D 模型、点云和 3DGS 还没有。
- ✅ **刚体物理引擎**：已经接入了 Rapier（WASM）。载具、机器人、Besiege 类玩法都建在它上面，不再另外引入 Jolt、Bullet 或 MuJoCo。
- ⬜ **建筑版本控制**：分支、diff、合并、回滚，多人协作搭建。

### AI 方向

- 🟡 **LLM 驱动的 NPC 和 Agent**：参考 Voyager、Mindcraft，让 AI 在里面自己干活。现在 Claude 已经能通过 MCP 操作世界。
- ⬜ 图片、3D 模型、草图转方块结构
- ⬜ 风格迁移：同一栋建筑换成中式、赛博朋克等风格
- ⬜ 自动给建筑做内饰和装修

### 真实世界方向

- ⬜ **OSM 地图导入**：已有项目 Arnis 可以参考。
- ⬜ **香港开放 LiDAR 和 DTM 数据**：香港地政总署有公开的高精度地形数据，非常适合"生成香港"。
- ⬜ 建筑 BIM/IFC 导入、Google 3D Tiles 导入
- ⬜ 天气、昼夜、潮汐对应真实数据

### 工程和机器人方向

- ⬜ 传感器：激光雷达、相机、IMU 输出给外部程序（agent 的 `shot` 已经能从任意相机截图）
- ⬜ **ROS2 桥接**：URDF 只是第一步，真正接上 ROS 才有科研价值。浏览器里通过 rosbridge 接入，见 plan.md。
- ⬜ Verilog 编译成红石、电路仿真
- 🟡 编程计算机：参考 ComputerCraft。Computer mod 已有终端、文件、编辑器和红石接口。
- ⬜ 流体和空气动力学，飞行器会用到（Aeronautics 已有简化的空气阻力、浮力和气压）

### 人工生命方向

- ⬜ Lenia（连续版的生命游戏）
- ⬜ 卡尔·西姆斯式的虚拟生物进化：身体加神经网络一起进化
- ⬜ L-system 植物生长
- ⬜ 生态系统：食物链和种群动态

### 创作和展示方向

- ⬜ MIDI 与音符盒双向转换
- ⬜ 导演台导出到 Blender 做光追渲染，参考 Replay Mod 和 Flashback
- ⬜ 数据可视化：把数据集做成 3D 方块图表
- ⬜ 教育用途：物理实验室、数学课件

## 五、优先级

全部做完是好几个团队好几年的工作量，所以把它当成**一个核心平台加一堆插件**，先做底层、复用最多的东西：

1. **子世界之间的关节**：Besiege 类玩法、更多载具、机器人都建在它上面（plan.md 的 P0）。
2. **锁步和 Python 接口**：RL、NetLogo、数学函数、生命游戏都会用到（plan.md 的 P2）。
3. **真实地形和 OSM 导入**：用"生成香港"和"复刻港科大"作为展示项目，效果直观。
4. **玩法包**：元素反应、枪械、吸血鬼幸存者这类放到最后，或者交给社区做。
